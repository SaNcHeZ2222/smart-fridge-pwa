# Свежо

Local-first PWA для домашнего учёта продуктов, сроков годности и быстрых завтраков.

## Возможности MVP

- холодильник и морозилка;
- добавление и списание продуктов вручную или сканированием;
- EAN/UPC и GS1 Data Matrix;
- автоматический поиск названия и объёма товара в Open Food Facts;
- личный локальный каталог: неизвестный товар достаточно описать один раз;
- короткое подтверждение места, количества и срока для знакомых товаров;
- сроки годности и экран «Сегодня»;
- семь завтраков с порциями для Ангелины, Саши и на двоих;
- список покупок, режим готовки и таймеры;
- локальная база IndexedDB;
- экспорт и импорт резервной копии;
- офлайн-режим после установки.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run check
```

## GitHub Pages

Репозиторий рассчитан на имя `smart-fridge-pwa`. После включения GitHub Pages с источником GitHub Actions каждый push в `main` публикует новую версию.

Данные холодильника не отправляются в репозиторий и хранятся только в браузере устройства. Для первого поиска незнакомого товара во внешний каталог Open Food Facts отправляется только GTIN/штрихкод; результаты затем запоминаются локально.
